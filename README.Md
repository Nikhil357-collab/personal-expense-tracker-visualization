# Personal Expense Tracker with Data Visualization

## Project Overview

Personal Expense Tracker is a Python-based finance analytics project that helps users manage and analyze expenses using CSV datasets, SQLite database integration, and interactive visualizations.

This project demonstrates:
- Data analysis
- Data visualization
- SQL integration
- Automation
- Dashboard development
- Reporting

---

# Problem Statement

Managing personal expenses manually is difficult and error-prone.

This project helps users:
- Track expenses
- Analyze spending habits
- Visualize monthly trends
- Understand category-wise spending
- Generate automated reports
